# `@workspace/integrations`

Server-side, optional provider helpers for ShareSpace. The package includes optional DeepSeek output compaction and a one-shot Google AI Studio/Gemini summarizer. Configure an available model ID and a server-only `GEMINI_API_KEY`; without the key, the helper returns `unavailable` without making a request.

`createSummarizeApprovedContext` accepts one explicit `callerApproved` boolean and a bounded list of at most 20 approved context items (32 KiB total). It does not accept or retrieve conversation history. A caller must select and approve the exact supplied context before invoking it. The request is sent through the official `@google/genai` SDK as a stateless `models.generateContent` call. Context is delimited as data and treated as untrusted input by the system instruction.

The response is constrained to JSON, parsed with Zod, and checked so every label cites an ID from the approved input. Invalid output, provider errors, timeouts, missing credentials, or browser invocation return `unavailable`; they do not produce an approval or clear decision. Labels and caveats are model-generated suggestions and still require application policy and human review. Abort is client-side cancellation; a timed-out provider request may still be processed or billed.

No endpoint, authentication path, Jev API, billing policy, or model-selection default is added here. The caller remains responsible for membership authorization, caller approval UX, deployment secrets, and sharing disclosures.


## Optional DeepSeek output compaction

`createDeepSeekCompactor` prepares a smaller stored representation of an explicitly approved tool output or diff. It defaults to `deepseek-flash` with thinking disabled and JSON output, using server-only `DEEPSEEK_API_KEY` and optional `DEEPSEEK_MODEL`. It performs no database writes and is not automatically wired into live capture. The adapter currently uploads bounded excerpts and metadata; adding provider summarization requires a separate local consent control and an authenticated server endpoint.

Input must include `summarizationConsent: true`, `redacted: true`, `kind`, `text`, `exact_error_excerpts`, and `relative_paths`. The caller must select the source and enforce repository/privacy boundaries before calling it. Input is capped at 64 KiB, and each exact error must occur in the supplied text. A second redaction pass removes known credentials and personal paths before the provider sees the source. No logs include prompts, keys or provider responses.

For sources below 2 KiB, missing credentials, timeout, failure, invalid JSON, or a summary that does not save bytes, the helper returns a bounded redacted fallback excerpt and the separately preserved error/path evidence. Exact error strings are copied after redaction, not generated by the model. Successful results expose input/stored byte counts, which include the preserved evidence. Model summaries remain lossy suggestions and must not become evidence of test success or a conflict-free decision. Defaults are a 5-second deadline, 600 output tokens and an 800-character summary; the response stream is bounded to 16 KiB.

The API format follows DeepSeek's [JSON output](https://api-docs.deepseek.com/guides/json_mode/) and [thinking-mode](https://api-docs.deepseek.com/guides/thinking_mode/) references. A harmless synthetic request through this helper was verified on 2026-10-03: 6,469 input bytes became 596 stored bytes with the exact error retained. This proves the helper/provider path; it does not mean live agent source is sent for summarization.
